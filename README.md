# BF2142 Demo Analyzer (v1.51)

Внешний прозрачный оверлей для разбора записей матчей (**BattleRecorder**) в **Battlefield 2142 v1.51**.

Утилита помогает администраторам серверов, судьям турниров и игрокам проверять спорные моменты на **WallHack** и **Aimbot**: показывает направление взгляда выбранного подозреваемого («лазер» или конечную точку прицела), интерактивный список игроков с переключением камеры BattleRecorder и считает углы доводки и удержания прицела.

Оверлей работает полностью снаружи процесса: **не изменяет файлы игры, не внедряет DLL и не меняет геймплейные структуры** — для работы используются только чтение памяти (`ReadProcessMemory`) и переключение выбранного игрока в штатной камере повтора BattleRecorder.

---

## Важное предупреждение (Disclaimer)

- Используйте утилиту **строго офлайн** при локальном просмотре демок BattleRecorder.
- **Не запускайте** оверлей при подключении к онлайн-серверам с античитом (**PunkBuster** и серверные проверки): античиты могут негативно реагировать на сторонние программы, читающие память процесса `BF2142.exe`.

---

## Подготовка игры и запуск

1. **Запустите BF2142 в оконном режиме.**
   Добавьте флаг `+fullscreen 0` в ярлык игры или параметры запуска лаунчера (при желании можно сразу задать разрешение, например `+fullscreen 0 +szx 1280 +szy 720`).

   > _Зачем это нужно:_ Windows не умеет рисовать внешний оверлей поверх классического полноэкранного режима DirectX 9. Но чтобы смотреть демку было удобно на весь экран, в самом оверлее есть кнопка **`F12`**, которая убирает рамки окна и делает полноценный **Borderless Fullscreen** («полный экран без рамки»).

2. **Откройте нужную демку в BattleRecorder.**
   Дождитесь загрузки карты и начала воспроизведения.

3. **Запустите `bf2142_overlay.exe` обычным двойным кликом.**
   > _Примечание:_ права администратора **не требуются**, если сама игра запущена без повышения прав. Запускать оверлей от имени администратора нужно только в том случае, если у вас `BF2142.exe` настроен на запуск с правами администратора (иначе Windows не даст читать память процесса игры).

## Горячие клавиши

Горячие клавиши срабатывают **только когда окно игры активно** (при сворачивании или `Alt-Tab` оверлей автоматически скрывается).

| Клавиша                   | Что делает                                                                                                                                                                                                                                                                                                       |
| :------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`F1`**                  | Показать / скрыть встроенную карточку справки по управлению поверх экрана                                                                                                                                                                                                                                        |
| **`Tab`**                 | Открыть / закрыть интерактивную таблицу игроков (`Scoreboard`): живые и мёртвые игроки обеих команд (`ID`, статус, ник, `K/D`, очки). Клик мышью сразу выбирает подозреваемого и переключает камеру BattleRecorder; двойной клик или **`↑` / `↓` + `Enter`** — выбирает и закрывает таблицу; **`Esc`** — закрыть |
| **`PageUp` / `PageDown`** | Переключить подозреваемого (и камеру наблюдения) на следующего / предыдущего живого игрока                                                                                                                                                                                                                       |
| **`F7`**                  | Переключить режим лазера выбранной цели по кругу: `Target Beam` (луч взгляда цели) -> `Target Dot` (только маркер конечной точки прицела) -> `Off` (выкл)                                                                                                                                                        |
| **`F8` / `F9`**           | Уменьшить / увеличить длину лазера (от `20 м` до `300 м`, шаг `10 м`)                                                                                                                                                                                                                                            |
| **`F11`**                 | Сбросить статистику анализатора прицеливания (`Snaps`, `LOCK`) и поставить разделительную отметку в `aim_log.txt`                                                                                                                                                                                                |
| **`F12`**                 | Включить / выключить «Полный экран без рамки» (Borderless Fullscreen) для оконного BF2142                                                                                                                                                                                                                        |
| **`Insert`**              | Показать / скрыть верхнюю информационную панель (HUD) и тонкую зелёную рамку выравнивания по краю окна игры                                                                                                                                                                                                      |
| **`=` (`+`) / `-`**       | Подстроить множитель масштаба проекции FOV (`0.40x–2.50x`), если при смене зума/оптики нужно подравнять наложение                                                                                                                                                                                                |
| **`End`**                 | Вернуть исходный вид окна игры (если был включён Borderless) и аккуратно закрыть оверлей                                                                                                                                                                                                                         |

## Как пользоваться анализом прицеливания (`Aim` и `aim_log.txt`)

1. **Выберите подозреваемого игрока.**
   Нажмите `Tab` и кликните по нужному игроку в таблице (или листайте живых игроков через `PageUp` / `PageDown`). Камера BattleRecorder переключится на выбранного игрока. Если подозреваемый погибает, выбор **не сбивается** — в HUD появится статус `DEAD`, а при возрождении наблюдение продолжится без потери накопленной статистики.

2. **Оцените обзор и прострелы через `F7`.**
   - Режим **`Target Beam`** рисует тонкий `1px` луч взгляда выбранного игрока — удобно смотреть, водит ли игрок прицелом по моделям врагов через стены и дым.
   - Режим **`Target Dot`** убирает саму линию и оставляет только маркер точки взгляда на заданной дистанции (`F8`/`F9`), если длинный луч мешает обзору.

3. **Как читать `[SNAP]` и `[LOCK]` в HUD и в файле `aim_log.txt`:**
   Когда рядом в секторе обзора цели (`<= 12°` и `<= 120 м`) находится противник, в HUD появляется строка `Aim -> ...`, а все подозрительные события автоматически сохраняются в текстовый файл `aim_log.txt` рядом с программой:
   - **`[SNAP]`** — резкое сокращение угла между прицелом игрока и ближайшим врагом за несколько тиков. Помогает заметить неестественно резкие «перескоки» доводки.
   - **`[LOCK]`** — удержание прицела на голове или корпусе врага с минимальным углом в течение длительного времени. Показывает средний угол, длительность в секундах и то, насколько за это время сдвинулся сам враг (`enemy moved`).

## Сборка из исходников

Для самостоятельной сборки нужен установленный **Go** (1.21+, внешний C-компилятор `CGO` не требуется). Сборка выполняется строго под 32-битную архитектуру (`GOARCH=386`), так как `BF2142.exe` является 32-битным приложением.

Откройте PowerShell в папке с проектом и выполните:

```powershell
$env:GOOS="windows"; $env:GOARCH="386"; $env:CGO_ENABLED="0"
go build -ldflags="-s -w" -o bf2142_overlay.exe ./cmd/overlay
```

При необходимости аналогично собирается диагностическая консольная утилита для проверки смещений в памяти:

```powershell
$env:GOOS="windows"; $env:GOARCH="386"; $env:CGO_ENABLED="0"
go build -ldflags="-s -w" -o bf2142_dumper.exe ./cmd/dumper
```
