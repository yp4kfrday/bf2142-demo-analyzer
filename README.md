# BF2142 Demo Analyzer (v1.51)

Внешний прозрачный оверлей для разбора записей матчей (**BattleRecorder**) в **Battlefield 2142 v1.51**.

Утилита помогает администраторам серверов, судьям турниров и игрокам проверять спорные моменты на **WallHack** и **Aimbot**: показывает рамки игроков, направление взгляда («лазеры» или конечную точку прицела), интерактивный список игроков и считает углы доводки/удержания прицела.

Оверлей работает полностью снаружи процесса: **не изменяет файлы игры, не внедряет DLL и не записывает ничего в память игры** — используется только безопасное чтение памяти (`ReadProcessMemory`).

---

## Важное предупреждение (Disclaimer)

- Используйте утилиту **строго офлайн** при локальном просмотре демок BattleRecorder.
- **Не запускайте** оверлей при подключении к онлайн-серверам с античитом (**PunkBuster** и серверные проверки): несмотря на режим «только чтение», античиты могут негативно реагировать на сторонние программы, читающие память процесса `BF2142.exe`.

---

## Подготовка игры и запуск

1. **Запустите BF2142 в оконном режиме.**
   Добавьте флаг `+fullscreen 0` в ярлык игры или параметры запуска лаунчера (при желании можно сразу задать разрешение, например `+fullscreen 0 +szx 1920 +szy 1080`).

   > _Зачем это нужно:_ Windows не умеет рисовать внешний оверлей поверх классического полноэкранного режима DirectX 9. Но чтобы играть и смотреть демку было удобно на весь экран, в самом оверлее есть кнопка **`F12`**, которая убирает рамки окна и делает полноценный **Borderless Fullscreen** («полный экран без рамки»).

2. **Откройте нужную демку в BattleRecorder.**
   Дождитесь загрузки карты и начала воспроизведения.

3. 3. **Запустите `bf2142_overlay.exe` обычным двойным кликом.**
      > _Примечание:_ права администратора **не требуются**, если сама игра запущена без повышения прав. Запускать оверлей от имени администратора нужно только в том случае, если у вас `BF2142.exe` настроен на запуск с правами администратора (иначе Windows не даст читать память процесса игры).

## Горячие клавиши

Горячие клавиши срабатывают **только когда окно игры активно**.

| Клавиша                   | Что делает                                                                                                                                                                                                                                                                   |
| :------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`Insert`**              | Показать / скрыть информационную панель (HUD) и тонкую зелёную рамку выравнивания по краю окна игры                                                                                                                                                                          |
| **`Tab`**                 | Открыть / закрыть интерактивную таблицу игроков (`Scoreboard`): живые и мёртвые игроки обеих команд (`ID`, статус, ник, `K/D`, очки). Клик мышью сразу выбирает подозреваемого; двойной клик или **`↑` / `↓` + `Enter`** — выбирает и закрывает таблицу; **`Esc`** — закрыть |
| **`PageUp` / `PageDown`** | Переключить подозреваемого на предыдущего / следующего живого игрока                                                                                                                                                                                                         |
| **`F6`**                  | Включить / выключить ESP (уголковые рамки, ники и дистанцию до игроков)                                                                                                                                                                                                      |
| **`F7`**                  | Переключить режим лазера по кругу: `Target Beam` (луч только у цели) -> `All Beams` (у всех) -> `Target Endpoint` (только маркер точки в конце взгляда цели) -> `All Endpoints` (только точки всех) -> `OFF` (выкл)                                                          |
| **`F8` / `F9`**           | Уменьшить / увеличить длину лазера (от `20 м` до `300 м`, шаг `10 м`)                                                                                                                                                                                                        |
| **`F10`**                 | Включить / выключить 3D-конус области прицеливания (`AimCone`) у выбранной цели                                                                                                                                                                                              |
| **`[` / `]`**             | Уменьшить / увеличить угол 3D-конуса прицеливания (`1°–20°`)                                                                                                                                                                                                                 |
| **`F11`**                 | Сбросить статистику анализатора прицеливания (`Snaps`, `LOCK`) и поставить разделительную отметку в `aim_log.txt`                                                                                                                                                            |
| **`F12`**                 | Включить / выключить «Полный экран без рамки» (Borderless Fullscreen) для оконного BF2142                                                                                                                                                                                    |
| **`=` (`+`) / `-`**       | Подстроить множитель масштаба проекции FOV (`0.40x–2.50x`), если при смене зума/оптики нужно подравнять наложение                                                                                                                                                            |
| **`End`**                 | Вернуть исходный вид окна игры (если был включён Borderless) и аккуратно закрыть оверлей                                                                                                                                                                                     |

## Как пользоваться анализом прицеливания (`Aim` и `aim_log.txt`)

1. **Выберите подозреваемого игрока.**
   Нажмите `Tab` и кликните по нужному игроку в таблице (или листайте живых игроков через `PageUp` / `PageDown`). Если выбранный игрок погибает, выбор **не сбивается** — в HUD появится статус `DEAD / [WAITING RESPAWN]`, а при возрождении наблюдение продолжится без потери накопленной статистики.

2. **Оцените обзор и прострелы через `F7`.**
   - Режим **`Target Beam`** рисует тонкий `1px` луч взгляда выбранного игрока — удобно смотреть, водит ли игрок прицелом по моделям врагов через стены и дым.
   - Режим **`Target Endpoint`** убирает саму линию и оставляет только маркер точки взгляда на заданной дистанции (`F8`/`F9`), если длинный луч мешает обзору.

3. **Как читать `[SNAP]` и `[LOCK]` в HUD и в файле `aim_log.txt`:**
   Все события автоматически сохраняются в текстовый файл `aim_log.txt` рядом с программой:
   - **`[SNAP]`** — резкое сокращение угла между прицелом игрока и ближайшим врагом (с угла `>= 2.5°` до `<= 1.5°` за несколько тиков). Помогает заметить неестественно резкие «перескоки» доводки.
   - **`[LOCK]`** — удержание прицела на голове или корпусе врага с минимальным углом (`~1.0°–1.5°`) в течение длительного времени. Показывает средний угол, длительность в секундах и то, насколько за это время сдвинулся сам враг (`enemy moved`).

## Сборка из исходников

Для самостоятельной сборки нужен установленный **Go** (1.20+, внешний C-компилятор `CGO` не требуется). Откройте PowerShell в папке с проектом и выполните:

```powershell
$env:GOOS="windows"; $env:GOARCH="386"; $env:CGO_ENABLED="0"; go build -ldflags="-s -w" -o bf2142_overlay.exe bf2142_overlay.go
```

При необходимости аналогично собирается диагностическая консольная утилита для проверки смещений в памяти:

```powershell
$env:GOOS="windows"; $env:GOARCH="386"; $env:CGO_ENABLED="0"; go build -ldflags="-s -w" -o bf2142_dumper.exe bf2142_dumper.go
```
