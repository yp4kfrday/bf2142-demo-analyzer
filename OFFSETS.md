# BF2142 v1.51 — Карта адресов и смещений памяти

Справочник статических указателей и смещений структур движка Refractor 2 (x86), используемых в `bf2142_overlay.go` и `bf2142_dumper.go` для чтения памяти через `ReadProcessMemory`.

## 1. Базовые модули и статические указатели

| Модуль / Указатель | Смещение (RVA) | Описание                                                                                      |
| :----------------- | :------------- | :-------------------------------------------------------------------------------------------- |
| `BF2142.exe`       | `0x67D068`     | Указатель на `ClassManager` (резервный поиск менеджеров через имя класса)                     |
| `BF2142.exe`       | `0x685228`     | Прямой указатель на `PlayerManager`                                                           |
| `RendDX9.dll`      | `0x1F8E58`     | Прямой указатель на `Renderer` (получен из пролога функции `WorldToScreen` по RVA `0x1988D0`) |

## 2. Цепочки указателей

- **Список игроков:** `PlayerManager` → `+0x10` (голова `std::list<CPlayer*>`), `+0x14` (`uint32` количество игроков)
- **Активная камера:** `Renderer` → `ActiveCamera` (цепочка чтения вьюпорта и матриц вида/проекции)

## 3. Структура `CPlayer`

| Смещение | Тип            | Поле                         | Примечание                                                             |
| :------- | :------------- | :--------------------------- | :--------------------------------------------------------------------- |
| `+0x64`  | `std::string`  | Никнейм игрока               | MSVC x86 layout (28 байт, SSO при `capacity < 16`)                     |
| `+0x84`  | `CViewMatrix*` | Указатель на матрицу взгляда | Используется для координат глаз, направления луча и проверки `IsAlive` |
| `+0xB8`  | `int32`        | Постоянный ID игрока         | Используется для стабильной привязки `Target`                          |
| `+0xD8`  | `int32`        | Команда (`Team`)             | `1` — EU / PAC, `2` — противоположная сторона                          |
| `+0x100` | `struct`       | Статистика игрока            | Счёт (`Score`), убийства (`Kills`), смерти (`Deaths`)                  |

## 4. Структура `CViewMatrix` (матрица игрока)

В BF2142 v1.51 строки матрицы `4×4` (`float32`) сдвинуты на `+0x10` относительно Battlefield 2:

| Смещение | Тип        | Поле              | Описание                                         |
| :------- | :--------- | :---------------- | :----------------------------------------------- |
| `+0xC8`  | `float[4]` | Row 0 (`Right`)   | Вектор вправо                                    |
| `+0xD8`  | `float[4]` | Row 1 (`Up`)      | Вектор вверх `(0, 1, 0)`                         |
| `+0xE8`  | `float[3]` | Row 2 (`LookDir`) | Единичный вектор направления взгляда (`Forward`) |
| `+0xF8`  | `float[3]` | Row 3 (`EyePos`)  | Мировые 3D-координаты глаз игрока `(X, Y, Z)`    |

## 5. Структура `ActiveCamera` (камера и проекция)

| Смещение | Тип           | Поле                  | Описание                                                         |
| :------- | :------------ | :-------------------- | :--------------------------------------------------------------- |
| `+0x10`  | `int32`       | `ViewportWidth`       | Ширина клиентской области рендера в пикселях                     |
| `+0x14`  | `int32`       | `ViewportHeight`      | Высота клиентской области рендера в пикселях                     |
| `+0x1C`  | `float32`     | `Aspect / FOV factor` | Используется в резервном расчёте проекции (`~1.0239` при 16:9)   |
| `+0x40`  | `float[4][4]` | `WorldMatrix`         | Мировая матрица камеры (позиция камеры на `+0x70`)               |
| `+0x80`  | `float[4][4]` | `ViewMatrix`          | Видовая матрица камеры (левосторонняя система координат DirectX) |
| `+0x140` | `float[4][4]` | `ProjMatrix`          | Матрица проекции камеры (основной расчёт `WorldToScreen`)        |
